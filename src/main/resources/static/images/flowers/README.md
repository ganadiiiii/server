# 꽃 이미지 파일 저장소

이 디렉토리에 꽃 이미지 파일들을 저장하세요.

## 필요한 이미지 파일들

다음 이름으로 이미지 파일을 저장해주세요 (png):

- `forsythia.png` - 개나리
- `gerbera.png` - 거베라
- `lilyvalley.png` - 은방울꽃
- `tulip.png` - 튤립
- `forgetmenot.png` - 물망초
- `rose.png` - 장미
- `lily.png` - 백합
- `carnation.png` - 카네이션
- `sunflower.png` - 해바라기

## 이미지 파일 요구사항

- 형식: PNG 권장
- 크기: 권장 300x300px 이상
- 파일명: 영어 소문자, 언더스코어(_) 사용 가능

## 접근 URL

이미지 파일들은 다음 URL로 접근할 수 있습니다:
`http://localhost:8080/images/flowers/{파일명}`

예: `http://localhost:8080/images/flowers/rose.png`
